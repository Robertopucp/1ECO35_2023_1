## Lectures Overview

This repository contains the materials for a 12-lecture Python and R programming course taught at the undergraduate level. Topics range from foundational programming concepts.

---

### Lecture 1 — Data Types and Data Structures
Introduction to core Python building blocks: variable types (`string`, `integer`, `boolean`, `float`), and fundamental data structures including `tuple`, `set`, `dictionary`, `array`, and matrices. Indexing and slicing are also covered.

---

### Lecture 2 — Control Flow and Functions
Conditional logic (`if`, nested `if`), iteration (`while`, `for` loop), error handling (`try/except`), and user-defined functions.

---

### Lecture 3 — Functional Programming
Lambda functions, `map()`, `apply()` on DataFrames and matrices, and flexible function arguments (`*args`, `**kwargs`).

---

### Lecture 4 — DataFrames and ETL
Introduction to `pandas` DataFrames. Covers data loading, transformation, and the Extract-Transform-Load (ETL) pipeline fundamentals.

---

### Lecture 5 — ETL Part II: Data Cleaning
Advanced data cleaning techniques including handling missing values, data type conversion, filtering, and reshaping datasets for analysis.

---

### Lecture 6 — Data Visualization
Data visualization in Python and R using `matplotlib`, `seaborn`, and `ggplot2`. Covers histograms, scatter plots, bar charts, and line graphs.

---

### Lecture 7 — Regular Expressions
Text processing using `regex` in Python. Pattern matching, string extraction, and text cleaning applied to real datasets.

---

### Lecture 8 — Extracting Data from PDFs
Scraping and extracting structured data from PDF documents.

---

### Lecture 9 — Linear Regression and Panel Data
Applied econometrics in Python and R: linear regression, coefficient plots, panel data models, and exporting results to LaTeX tables.

---

### Lecture 10 — Web Scraping
Automated data collection from websites using `requests` and `BeautifulSoup`. Covers static and dynamic content extraction.

---

### Lecture 11 and 12 — Geospatial Data
Geospatial data handling in Python. Topics include reading shapefiles, spatial joins, and map visualization.
